# Generated Magic Search fixture recipes

The baseline produces deterministic normalized vectors and simple metadata fields in memory. They
exist only to exercise scale, exact retrieval, deterministic filters, and hybrid-ranking plumbing;
they do not represent images, people, objects, captions, or a semantic model.

Future non-generated benchmark fixtures must document the dataset source, SPDX/license reference,
checksum, derivation, annotation provenance, privacy review, and intended assertion. Private
customer images, the AI Test project, wedding photographs, identity labels, demographic labels,
model weights, and cloud-generated data must never be committed here.
