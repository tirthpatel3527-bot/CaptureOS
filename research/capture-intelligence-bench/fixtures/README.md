# Generated fixture recipes

The baseline suite generates checkerboards, gradients, dark/bright frames, and scalable descriptor catalogs in memory. No client media, trained model, or third-party photograph is committed here. Future licensed visual fixtures must include source, SPDX license, checksum, and derivation metadata.

Generated variants should document their recipe and intended assertion (for example: resize/recompression tolerance, small crop robustness, Gaussian-like blur ordering, directional blur uncertainty, highlight/shadow clipping evidence, or unrelated-frame separation). Private client media may be used only for manual local validation and must never be committed here.
