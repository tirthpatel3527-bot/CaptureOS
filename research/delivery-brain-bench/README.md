# DeliveryBrainBench

`delivery-brain-bench` is a deterministic, generated-data benchmark for M9 manifest planning and
the existing local streaming verified-copy primitive. It opens no CaptureOS catalog, AI Test
project, customer media, preview, model, embedding, note, external path, or network service.

Run it with:

```sh
cargo run --release -p delivery-brain-bench -- --suite baseline
```

The baseline measures generated 100, 1k, 10k, 50k, and 100k candidate sets, deterministic
manifest checksum stability, unique-destination collision indexing, and a set-based resume lookup.
It also copies a 2 MiB generated byte fixture twice through `ingest::copy_and_verify`, confirming
the first streaming BLAKE3 verified copy and second identical-file reuse.

Timings and lower-bound input-memory estimates describe the current machine and generated fixture,
not a customer-catalog performance guarantee. The benchmark does not claim creative quality,
media-decoder support, storage throughput, or full 100 GB copy throughput. It exists to catch
accidental O(n²) manifest/collision behavior without handling any photographer data.
