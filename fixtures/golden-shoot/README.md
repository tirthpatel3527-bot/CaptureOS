# Golden Shoot fixture

This is a synthetic fixture, intentionally free of copyrighted or private wedding media. It represents two cameras, an audio recorder, a master SSD, and an offline backup HDD.

The loader creates five logical assets and six physical file instances. One RAW asset intentionally has no backup copy so later CaptureGuardian work has a known coverage gap. Placeholder media is not used in Phase 0 because no decoder, indexer, or filesystem scanner is implemented.
